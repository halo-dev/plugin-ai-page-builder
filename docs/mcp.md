# 外部 Agent 接入

[返回 README](../README.md)

安装并启用 **[MCP Server](https://www.halo.run/store/apps/app-ybv96zol) 1.3.0 或更高版本**后，在「工具 → MCP 服务」创建访问密钥，选择 AI 页面工坊的工具。连接端点为站点的 `/mcp`，客户端配置参阅 [MCP Server 文档](https://www.halo.run/store/apps/app-ybv96zol#快速开始)。

可用工具覆盖页面查询、创建、更新、精确补丁、预览、发布、下线和历史恢复。编辑、预览、发布和下线可以分别授权；工具以密钥所有者身份操作。修改已有页面时需要携带读取到的版本号，遇到冲突应重新读取，不要强制覆盖。

预览链接有效期为 15 分钟，持有者无需登录即可查看；请将其视为临时凭证妥善保管。

## 提示词示例

可以这样向 Codex、Claude Code 等客户端描述任务：

- 「使用 AI 页面工坊的工具读取当前主题，为『2026 春季新品发布』创建一个路径为 `spring-launch` 的活动页，复用主题布局。完成后给我预览链接，先不要发布。」
- 「读取 `about` 页面，把首屏标题改成『让内容回到创作本身』，并用预览链接检查移动端效果。只保存草稿，不要发布。」
- 「检查 `pricing` 页面在手机端是否有布局溢出，用精确补丁做最小修改，预览后告诉我改了哪些内容。」
- 「列出最近更新的页面，找出已发布但草稿还有未发布修改的页面。」
