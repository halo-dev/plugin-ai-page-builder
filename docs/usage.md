# 使用指南

[返回 README](../README.md)

## 新建页面

- **AI 创建**：描述页面需求、选择模型并发送，AI 会立即开始生成并在编辑器中展示进度。
- **手动创建**：填写标题并选择是否复用主题布局，创建空白页面后自行编辑。
- **导入页面**：选择 ZIP 压缩包，完成 AI 安全审查后创建未发布页面。

## 编辑页面

编辑器提供三种视图：

- **编辑**：在可视化画布中修改内容；画布不执行页面脚本。
- **源码**：直接编辑 HTML、CSS 和 JavaScript。修改可视化页面的源码后会转换为代码模式，原有编辑数据仍保留在历史版本中。
- **运行**：在沙箱中运行已保存的草稿，检查脚本和交互效果。

编辑支持撤销、重做和多端预览。保存前会校验内容；AI 运行期间页面会暂时锁定。页面设置中可以修改标题、描述、访问路径、是否复用主题布局和是否禁止公开访问；开启「禁止公开访问」后，公开链接只有超级管理员可以访问，其他访客会看到 404。

## 预览与发布

未发布页面可以从页面列表或编辑器打开预览。发布要求草稿已保存且内容校验通过，首次发布时设置访问路径；页面包含 JavaScript 时，发布前会要求确认。发布后，「更新发布」会用当前草稿替换线上内容；取消发布只移除公开访问，草稿和历史记录都会保留。

预览使用隔离沙箱；发布后脚本会在站点环境执行，请只发布已经检查并信任的页面内容。

## 历史版本

历史版本支持多端预览和代码差异。恢复历史版本会创建新的草稿，不会自动发布，也不会恢复访问路径或主题布局。

## 导入与导出

页面列表中的「导出」会打包已保存的草稿。导入 ZIP 的根目录需要包含 `page.json`、`page.html`、`styles.css` 和 `script.js`，其中 `page.json` 的格式如下：

```json
{
  "format": "ai-page-builder",
  "version": 1,
  "title": "关于我们",
  "description": "页面描述",
  "themeLayout": true
}
```

`description` 可省略，其余字段必填。导出包中的 `index.html` 仅用于本地预览，重新导入时请编辑 `page.html`。

导入前必须通过 AI 安全审查：`safe` 报告可直接导入，`suspicious` 报告需要确认风险，`malicious` 报告禁止导入。AI 不可用或审查失败时会禁止导入。审查结果与文件内容绑定并保留 30 分钟，文件变化或服务重启后需要重新审查。

上传的 ZIP 和解压后总大小不得超过 4 MiB，最多 64 个条目。图片、字体等外部资源保留原链接，不包含在导出包中。
