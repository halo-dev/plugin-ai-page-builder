# AI 页面工坊

用自然语言创建、编辑和发布 Halo 的主题扩展页面。AI 会结合当前主题与站点内容生成页面；你也可以在可视化画布中直接调整，或切换到源码模式编辑 HTML、CSS 和 JavaScript。

## 功能特性

- **AI 生成页面**：描述需求即可从空白开始生成，AI 会参考当前主题的布局、样式和亮暗模式。
- **对话式迭代**：生成过程实时预览，可随时补充要求、回答澄清问题或停止；中断后能继续生成。
- **可视化编辑**：点选元素修改文字、链接、图片，调整顺序或删除，也可以添加批注交给 AI 修改。
- **源码与运行预览**：内置 HTML / CSS / JavaScript 编辑器；「运行」模式可在沙箱中检查脚本交互。
- **多端预览**：支持桌面、平板和手机三档视口，以及主题的亮暗模式。
- **历史版本**：可预览、查看代码差异，并恢复为新草稿。
- **主题集成**：可复用主题的页头页尾与基础样式，也可独立渲染。
- **导入导出**：将草稿导出为 ZIP；导入前由 AI 进行安全审查。
- **MCP 外部 Agent**：通过 MCP Server 让 Codex、Claude Code 等客户端管理页面。
- **页面管理**：支持搜索、筛选、克隆、发布、取消发布和删除。

## 使用场景

- **快速上线落地页**：用一句话描述活动、产品或服务，快速生成可发布的页面。
- **制作品牌与介绍页面**：生成公司介绍、品牌故事、团队成员等长期展示页面。
- **整理站点内容**：参考已有文章、独立页面和附件，把分散的内容整理成专题页。
- **迭代已有页面**：在现有页面上继续对话调整，或直接在画布中修改局部内容。
- **迁移与复用页面**：导出页面后导入到其他站点，或克隆现有页面快速创建新版本。
- **外部 Agent 协作**：在 Codex、Claude Code 等客户端中批量创建、更新和预览页面。

## 使用要求

- Halo 2.26.0 或更高版本。
- 当前版本仅支持单实例部署，且仅超级管理员可用。
- AI 生成和导入安全审查需要安装并启用 AI Foundation 1.1.1 或更高版本，并配置支持工具调用的语言模型。
- 外部 Agent 接入需要 MCP Server 1.3.0 或更高版本；不安装不影响手动创建和编辑。

## 安装

1. 从 [GitHub Releases](https://github.com/halo-dev/plugin-ai-page-builder/releases) 下载 Assets 中的 JAR 文件，或在 Halo 应用市场安装（上架后补充链接）。
2. 在 Halo Console 的「插件」中安装并启用。安装与更新方式参阅 [Halo 文档](https://docs.halo.run/user-guide/plugins)。
3. 如需 AI 生成，安装并启用 AI Foundation，在 Console 中配置 Provider、模型和默认语言模型。
4. 从「内容 → 页面工坊」进入。

## 使用

### 新建页面

- **AI 创建**：描述页面需求、选择模型并发送，AI 会立即开始生成并在编辑器中展示进度。
- **手动创建**：填写标题并选择是否复用主题布局，创建空白页面后自行编辑。
- **导入页面**：选择 ZIP 压缩包，完成 AI 安全审查后创建未发布页面。

### 编辑页面

编辑器提供三种视图：

- **编辑**：在可视化画布中修改内容；画布不执行页面脚本。
- **源码**：直接编辑 HTML、CSS 和 JavaScript。修改可视化页面的源码后会转换为代码模式，原有编辑数据仍保留在历史版本中。
- **运行**：在沙箱中运行已保存的草稿，检查脚本和交互效果。

编辑支持撤销、重做和多端预览。保存前会校验内容；AI 运行期间页面会暂时锁定。页面设置中可以修改标题、描述、访问路径和是否复用主题布局。

### 预览与发布

未发布页面可以从页面列表或编辑器打开预览。发布要求草稿已保存且内容校验通过，首次发布时设置访问路径；页面包含 JavaScript 时，发布前会要求确认。发布后，「更新发布」会用当前草稿替换线上内容；取消发布只移除公开访问，草稿和历史记录都会保留。

预览使用隔离沙箱；发布后脚本会在站点环境执行，请只发布已经检查并信任的页面内容。

### 历史版本

历史版本支持多端预览和代码差异。恢复历史版本会创建新的草稿，不会自动发布，也不会恢复访问路径或主题布局。

## 导入与导出

页面列表中的「导出」会打包已保存的草稿。导入 ZIP 的根目录需要包含 `page.json`、`page.html`、`styles.css` 和 `script.js`，其中 `page.json` 的格式如下：

```json
{
  "format": "ai-page-builder",
  "version": 1,
  "title": "关于我们",
  "description": "页面描述",
  "themeLayout": true
}
```

`description` 可省略，其余字段必填。导出包中的 `index.html` 仅用于本地预览，重新导入时请编辑 `page.html`。

导入前必须通过 AI 安全审查：`safe` 报告可直接导入，`suspicious` 报告需要确认风险，`malicious` 报告禁止导入。AI 不可用或审查失败时会禁止导入。审查结果与文件内容绑定并保留 30 分钟，文件变化或服务重启后需要重新审查。

上传的 ZIP 和解压后总大小不得超过 4 MiB，最多 64 个条目。图片、字体等外部资源保留原链接，不包含在导出包中。

## 外部 Agent / MCP

安装并启用 **MCP Server 1.3.0 或更高版本**后，在「工具 → MCP 服务」创建访问密钥，选择 AI 页面工坊的工具。连接端点为站点的 `/mcp`，客户端配置参阅 [MCP Server 文档](https://github.com/halo-dev/plugin-mcp-server#快速开始)。

可用工具覆盖页面查询、创建、更新、精确补丁、预览、发布、下线和历史恢复。编辑、预览、发布和下线可以分别授权；工具以密钥所有者身份操作。修改已有页面时需要携带读取到的版本号，遇到冲突应重新读取，不要强制覆盖。

预览链接有效期为 15 分钟，持有者无需登录即可查看；请将其视为临时凭证妥善保管。

### 提示词示例

可以这样向 Codex、Claude Code 等客户端描述任务：

- 「使用 AI 页面工坊的工具读取当前主题，为『2026 春季新品发布』创建一个路径为 `spring-launch` 的活动页，复用主题布局。完成后给我预览链接，先不要发布。」
- 「读取 `about` 页面，把首屏标题改成『让内容回到创作本身』，并用预览链接检查移动端效果。只保存草稿，不要发布。」
- 「检查 `pricing` 页面在手机端是否有布局溢出，用精确补丁做最小修改，预览后告诉我改了哪些内容。」
- 「列出最近更新的页面，找出已发布但草稿还有未发布修改的页面。」

## 开发

需要 Java 21、Node.js >= 22.12.0、pnpm 10.33.0 和 Docker。

```bash
# 安装前端依赖
pnpm --dir ui install --frozen-lockfile

# 启动本地 Halo（http://localhost:8090，默认 admin / admin）
bash gradlew haloServer

# 另开终端，监听并重建前端资源
pnpm --dir ui dev

# 测试
bash gradlew test -x processUiResources
pnpm --dir ui test:unit --run
pnpm --dir ui type-check

# 完整构建，JAR 输出到 build/libs/
CI=true bash gradlew build
```

修改后端 API 后，重新生成前端客户端：

```bash
bash gradlew generateApiClient -x processUiResources -x test -x :ui:check
```
