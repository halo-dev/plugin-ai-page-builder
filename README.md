## 运行与存储约定

插件仅支持单机部署。每个页面同时执行一轮 Agent，整个插件最多驻留 4 轮运行；超出时
返回 HTTP 429，不在服务端排队。运行的活动时间上限为 10 分钟，等待用户回答时暂停该计时；
问题超过 24 小时未回答后运行中断，保留 checkpoint，用户可以显式继续。

关闭浏览器或 SSE 断线不会取消已预约的运行。用户点击停止时先持久化取消意图，停止后
清除恢复点；插件禁用或服务停机则中断运行并尽力保留恢复点。停机最多等待 20 秒收尾，
未能确认的写入留待恢复核对，不报告保存成功。已经进入页面提交阶段的运行不会被强制
标记为取消。重新启用后不会自动调用模型，继续生成需要用户操作。

`runId` 标识一次运行：普通重复提交返回 HTTP 409，客户端应查询原运行结果；相同的恢复
请求在本地运行仍存在时可复用原事件流。恢复必须匹配 checkpoint、页面版本和原运行身份。

会话响应的 `modelContextWindow` 表示送入模型的历史窗口（最近最多 20 轮、256 KiB），
不表示聊天记录保留期限。更早的聊天记录仍可分页读取，直到用户删除会话或页面。
页面删除先持久化删除意图及 finalizer，清理 revisions、会话、turn 和 checkpoint；失败后
控制器会重试，服务重启后也会继续清理。会话删除中断后，在再次读取时继续清理。

资源预算分别计算：模型输出与工具交互每轮累计 2 MiB；完整模型输入（system、消息和
工具定义）每次最多 256 KiB；单次输出最多 16,384 token；已报告的整轮用量达到
1,000,000 token 后停止继续调用。输入字节不是 tokenizer 的精确 token 数，模型自身上下文
限制仍由供应商校验；累计 token 限制在每步收到 usage 后检查，可能超出一次请求的用量，
缺失 usage 不按零计费，也无法据此保证真实账单上限。

临时预览有独立的 16 MiB 累计传输预算；超过后暂停发送预览快照，生成与最终保存继续。
checkpoint 单对象最多 2 MiB。归档中的 `usage` 记录模型、prompt 版本、已报告 token、
缺失 usage 的步骤数、耗时以及工具、预览、最大上下文字节数。

## 页面属性与内容版本

`ThemePage` 保存标题、描述、访问路径和主题布局。保存这些属性后立即生效，已发布页面也使用
最新属性；属性修改不会创建 revision，也不会标记有未发布的内容。一次属性保存使用同一个
页面版本校验，校验或路径冲突时整次保存失败。

revision 只记录 HTML、CSS、JS 及编辑器数据。发布选择内容版本，历史恢复只创建内容草稿，
不会回滚页面属性；历史预览也使用当前属性。AI 的标题和路径修改先暂存于本轮工作副本，
整轮成功提交后生效；失败或取消不保存暂存修改。

## 页面导入与导出

页面列表中的导出会打包**已保存的草稿**。在新建页面中点击「导入页面」，选择 ZIP 后必须
先通过 AI 安全审查；审查报告会列出风险等级、问题文件、证据片段和说明，确认报告后才会
创建新的未发布页面并进入编辑器。导入保留标题、描述、主题布局设置及 HTML、CSS、JS，
不继承原页面 ID、访问路径、发布状态、对话或历史版本。导入后可在发布时设置访问路径。

AI 审查依赖已启用并配置语言模型的 AI Foundation。默认使用 AI Foundation 配置的默认语言模型，
也可以在导入弹窗中选择其他语言模型。`safe` 报告可直接导入；
`suspicious` 报告需要勾选确认风险后才能导入；`malicious` 报告禁止导入。同一 ZIP 在审查
结果有效期内一旦被判定为 `malicious`，不能通过重新审查或更换模型绕过；需等待结果过期后
重新审查。AI Foundation 不可用、审查超时或结构化结果无法解析时会禁止导入（失败关闭）。
审查结果在服务端内存中保留 30 分钟，并与上传 ZIP 的 SHA-256 绑定；服务重启、结果过期或
重新选择文件后需要再次审查。审查状态保存在当前 Halo 进程的内存中。审查请求可能持续
数分钟，反向代理需要允许足够的超时。审查会把页面标题、描述、主题布局以及 `page.html`、`styles.css`、`script.js`
的内容发送给所选语言模型（未选择时为 AI Foundation 配置的默认模型）；AI 审查是辅助判断，
不替代发布前的人工检查。

ZIP 根目录必须包含以下四个 UTF-8 文件；符合格式的手工制作文件包也可以导入：

| 文件 | 内容 |
| --- | --- |
| `page.json` | 页面元数据，格式如下 |
| `page.html` | 原始 HTML 正文片段，不包含 `html`、`head`、`body` 外壳 |
| `styles.css` | 原始 CSS，可为空 |
| `script.js` | 原始 JavaScript，可为空 |

```json
{
  "format": "ai-page-builder",
  "version": 1,
  "title": "关于我们",
  "description": "页面描述",
  "themeLayout": true
}
```

`description` 可省略或为 `null`，其余字段必填。`version` 是文件包格式版本。
支持带 UTF-8 BOM 的 `page.json` 和带 `./` 前缀的根目录条目；规范化后重复的文件名会被拒绝。
导入内容需要符合插件已有的页面内容校验规则。导出附带的 `index.html` 用于本地预览，
`README.txt` 说明使用方式，两者不参与导入。修改后重新导入时，请编辑 `page.html`，
而不是 `index.html`。没有 `page.json` 的旧版导出包不支持导入。

上传 ZIP 和解压后文件总大小均不得超过 4 MiB，最多 64 个条目，`page.json` 不超过 16 KiB。
图片、字体等外部资源保留原链接，不包含附件实体或主题文件；分享至其他站点时需要确认这些资源
仍可访问。开启主题布局的页面使用导入站点当前主题，因此外观可能随主题而变化。

草稿、历史版本和未保存内容的预览响应使用 CSP 沙箱：允许脚本操作当前页面 DOM，
但不授予站点同源权限；外部脚本与样式、表单提交、嵌套页面、worker 和 Console API
均被禁止，网络请求仅按公开路由放行本站 public API（`/apis/api.*`）。图片、字体和媒体
仍按普通浏览器规则加载，外链图片不会被拦截；主题的 CSS、字体和模块脚本通过 `null`
来源的 CORS 响应继续加载。依赖站点本地存储（`localStorage` 等）的主题功能在预览中
可能不可用。发布后脚本会在站点环境执行，请仅发布已经检查并信任的页面源码。超级管理员
以及可切回原管理员的模拟登录会话访问发布页时，页面脚本会被停用以避免其读取管理员
会话，页面顶部会显示提示；请通过预览或无痕窗口查看访客效果。

## 外部 Agent / MCP

安装并启用 **MCP Server 1.3.0 或更高的 1.x 版本**后，在「工具 → MCP 服务」创建访问密钥，
选择 AI 页面工坊的工具。MCP 接入是可选能力：不安装 MCP Server 不影响插件使用；外部 Agent
通过 MCP 编辑页面不依赖 AI Foundation。连接端点为站点的 `/mcp`，客户端配置参阅
[MCP Server 文档](https://github.com/halo-dev/plugin-mcp-server#快速开始)。

工具协议名称由 MCP Server 自动添加插件前缀，例如 `ai-page-builder__get_page`。
编辑、预览、发布和下线分别授权；只需要生成草稿的密钥无需授予发布或下线工具。
工具以密钥所有者身份操作，不接受客户端指定操作者。当前领域权限仅支持超级管理员。
所有工具均声明输入和输出 JSON Schema，成功结果通过 `structuredContent` 返回并由 MCP Server
校验。未设置的可选字段会省略，例如未发布页面的 `publishedRevision`；错误使用 MCP 错误结果，
不套用成功结果的输出 Schema。

| 本地工具名 | 用途 |
| --- | --- |
| `get_page_capabilities` | 读取页面格式、内容限制与推荐流程 |
| `get_theme_context` | 读取当前主题或指定页面的布局、样式及亮暗模式约束 |
| `list_pages` | 分页搜索页面摘要 |
| `get_page` | 读取草稿、发布内容或指定历史 revision 的源码 |
| `create_page` | 用明确标题、路径和主题布局创建空白未发布页面 |
| `update_page` | 按字段保存 HTML/CSS/JS 草稿，省略字段保持原值 |
| `update_page_properties` | 保存标题、描述、路径和主题布局，立即影响已发布页面 |
| `patch_page` | 使用版本和源码 hash，原子应用精确文本替换 |
| `preview_page` | 为指定草稿签发短期浏览器预览链接 |
| `publish_page` | 发布指定的当前草稿版本 |
| `unpublish_page` | 下线页面，保留草稿和历史 |
| `list_page_revisions` | 分页读取版本历史 |
| `restore_page_revision` | 恢复历史内容为新草稿，不自动发布 |

推荐流程：读取规范和主题上下文 → 创建/读取页面 → 更新或补丁保存 → 获取预览链接 →
使用浏览器验证桌面、移动端和交互 → 发布。插件不替外部 Agent 调用模型、截图或管理对话。
内容校验通过不代表布局和运行行为正确；JS 校验仅检查长度与传输格式，发布前仍须检查源码。

已有页面的修改操作必须携带读取到的 `expectedVersion`，发布和预览还须携带 `expectedDraftRevision`。
补丁使用 `get_page` 返回的草稿 `baseHash`，一批修改必须在原始源码中唯一匹配且互不重叠；
任一失败整批不保存。遇到 `CONFLICT` 需重新读取并核对修改，不要强制覆盖或自动改用全量更新。
更新和补丁操作每次实际变化保存一个草稿版本，内容未变化不生成历史版本；恢复会创建新草稿。
内容编辑与历史恢复均不会自动发布；属性保存立即生效。

修改可视化页面的 HTML/CSS/JS 会转为源码模式，旧编辑数据保留在历史版本中，可通过恢复取回；
属性修改不改变编辑模式。`get_page` 的顶层属性始终来自当前页面，`document` 只包含源码，
不返回可视化编辑器内部数据。恢复不改变标题、描述、路径或主题布局。
创建遇到重复路径会返回冲突；请求结果不明确时先查询页面核对，不要改用随机路径重复创建。

预览要求 Halo 配置可访问的绝对外部地址。链接持有者无需登录即可访问绑定的草稿，链接应视为
临时凭证妥善保管。有效期为 15 分钟，同一操作者为同一页面重新签发、页面版本变化、页面删除、
插件停用或服务重启均会使旧链接失效。内存最多保留 128 条链接，满额时最早到期的链接会提前
失效。密钥轮换不会立即撤销已签发链接。预览始终以匿名访客身份渲染，沿用 CSP 沙箱并禁止缓存、
索引和 Referer 传递；它使用当前主题，不保存主题快照。修改主题后应重新验证页面效果。
凭证只保留在预览宿主页，主题与草稿脚本在独立的沙箱文档中执行，无法读取宿主页地址或 DOM。
