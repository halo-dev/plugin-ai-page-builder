## 页面导入与导出

页面列表中的导出会打包**已保存的草稿**。在新建页面中点击「导入页面」，选择 ZIP 后必须
先通过 AI 安全审查；审查报告会列出风险等级、问题文件、证据片段和说明，确认报告后才会
创建新的未发布页面并进入编辑器。导入保留标题、描述、主题布局设置及 HTML、CSS、JS，
不继承原页面 ID、访问路径、发布状态、对话或历史版本。导入后可在发布时设置访问路径。

AI 审查依赖已启用并配置语言模型的 AI Foundation。默认使用 AI Foundation 配置的默认语言模型，
也可以在导入弹窗中选择其他语言模型。`safe` 报告可直接导入；
`suspicious` 报告需要勾选确认风险后才能导入；`malicious` 报告禁止导入。AI Foundation
不可用、审查超时或结构化结果无法解析时会禁止导入（失败关闭）。审查结果在服务端内存中
保留 30 分钟，并与上传 ZIP 的 SHA-256 绑定；服务重启、结果过期或重新选择文件后需要再次
审查。审查会把页面标题、描述、主题布局以及 `page.html`、`styles.css`、`script.js`
的内容发送给所选语言模型（未选择时为 AI Foundation 配置的默认模型）；AI 审查是辅助判断，
不替代发布前的人工检查。

ZIP 根目录必须包含以下四个 UTF-8 文件；符合格式的手工制作文件包也可以导入：

| 文件 | 内容 |
| --- | --- |
| `page.json` | 页面元数据，格式如下 |
| `page.html` | 原始 HTML 正文片段，不包含 `html`、`head`、`body` 外壳 |
| `styles.css` | 原始 CSS，可为空 |
| `script.js` | 原始 JavaScript，可为空 |

```json
{
  "format": "ai-page-builder",
  "version": 1,
  "title": "关于我们",
  "description": "页面描述",
  "themeLayout": true
}
```

`description` 可省略或为 `null`，其余字段必填。`version` 是文件包格式版本。
支持带 UTF-8 BOM 的 `page.json` 和带 `./` 前缀的根目录条目；规范化后重复的文件名会被拒绝。
导入内容需要符合插件已有的页面内容校验规则。导出附带的 `index.html` 用于本地预览，
`README.txt` 说明使用方式，两者不参与导入。修改后重新导入时，请编辑 `page.html`，
而不是 `index.html`。没有 `page.json` 的旧版导出包不支持导入。

上传 ZIP 和解压后文件总大小均不得超过 4 MiB，最多 64 个条目，`page.json` 不超过 16 KiB。
图片、字体等外部资源保留原链接，不包含附件实体或主题文件；分享至其他站点时需要确认这些资源
仍可访问。开启主题布局的页面使用导入站点当前主题，因此外观可能随主题而变化。

草稿、历史版本和未保存内容的预览响应使用 CSP 沙箱：允许脚本操作当前页面 DOM，
但不授予站点同源权限；外部脚本与样式、表单提交、嵌套页面、worker 和 Console API
均被禁止，网络请求仅按公开路由放行本站 public API（`/apis/api.*`）。图片、字体和媒体
仍按普通浏览器规则加载，外链图片不会被拦截；主题的 CSS、字体和模块脚本通过 `null`
来源的 CORS 响应继续加载。依赖站点本地存储（`localStorage` 等）的主题功能在预览中
可能不可用。发布后脚本会在站点环境执行，请仅发布已经检查并信任的页面源码。超级管理员
以及可切回原管理员的模拟登录会话访问发布页时，页面脚本会被停用以避免其读取管理员
会话，页面顶部会显示提示；请通过预览或无痕窗口查看访客效果。
